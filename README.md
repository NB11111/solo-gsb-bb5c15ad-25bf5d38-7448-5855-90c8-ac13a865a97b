# 骑马钉小册子拼版检查工具

一个用于检查骑马钉（Saddle-Stitch）小册子拼版的 Web 应用。输入成品页数后自动补齐至 4 的倍数，生成每张纸正反两面的左右页码与空白版位，并按装订后的嵌套顺序预览。支持交换 / 编辑任意版位，实时校验重复页、缺页与同张纸正反配对异常，校验通过后可导出 CSV。

技术栈：Node.js + Express + 原生 HTML/CSS/JavaScript（无前端框架、无构建步骤）。

## 快速开始（Docker）

```bash
docker compose up --build
```

启动后访问 <http://localhost:3000>。

## 本地开发

```bash
npm install
npm start        # http://localhost:3000
npm test         # 运行拼版逻辑单元测试
```

## 功能

- **自动补齐**：成品页数自动补齐为 4 的倍数，补出的页以「空白」版位呈现。
- **嵌套顺序预览**：纸张按装订后的套叠顺序排列，第 1 张为最外层，逐张向内（缩进示意）。
- **版位交换**：交换模式下依次点击任意两个版位即可交换其页码。
- **版位编辑**：编辑模式下点击版位可直接输入页码或设为空白。
- **实时校验**：
  - 重复页：同一有内容页出现多次；
  - 缺页：有内容页未出现在任何版位；
  - 同张正反配对异常：空白错位、左版应为偶数页 / 右版应为奇数页、每面左右页码之和应为 N+1、正面左↔反面右（及正面右↔反面左）应同属一张书叶（连续页）、纸张页码组合与套帖顺序不符。
- **错误禁止导出**：存在任何错误时「导出 CSV」按钮禁用，服务端导出接口同样会拒绝。
- **CSV 导出**：包含纸张序号、面别、左版页码、右版页码（带 BOM，Excel 可直接打开）。

## 拼版规则

总页数 N（4 的倍数），共 N/4 张纸。第 i 张纸（1 起，最外层为第 1 张）：

| 面别 | 左版 | 右版 |
| ---- | ---------- | ---------- |
| 正面 | N − 2(i−1) | 2i − 1 |
| 反面 | 2i | N − 2i + 1 |

例如 8 页成品：第 1 张 正面[8, 1] / 反面[2, 7]，第 2 张 正面[6, 3] / 反面[4, 5]。

## API

| 方法 | 路径 | 说明 |
| ---- | ---- | ---- |
| POST | `/api/generate` | 入参 `{ "pages": 6 }`，返回标准拼版（含空白版位） |
| POST | `/api/validate` | 入参为拼版状态，返回 `{ valid, errors, slotErrors }` |
| POST | `/api/export` | 校验通过返回 CSV 文件；存在错误返回 400 |
| GET | `/api/health` | 健康检查 |

版位内容：页码（整数）或 `null`（空白）。

## CSV 格式

```csv
纸张序号,面别,左版页码,右版页码
1,正面,空白,1
1,反面,2,空白
2,正面,6,3
2,反面,4,5
```
